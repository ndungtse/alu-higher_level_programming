The ``2-matrix_divided`` module
===============================

Using ``matrix_divided``
------------------------

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Dividing a matrix returns a new rounded matrix:

    >>> matrix_divided([[1, 2, 3], [4, 5, 6]], 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix is left unchanged:

    >>> matrix = [[2, 4], [6, 8]]
    >>> matrix_divided(matrix, 2)
    [[1.0, 2.0], [3.0, 4.0]]
    >>> matrix
    [[2, 4], [6, 8]]

Dividing by zero raises a ZeroDivisionError:

    >>> matrix_divided([[1, 2], [3, 4]], 0)
    Traceback (most recent call last):
    ZeroDivisionError: division by zero

Rows of different sizes raise a TypeError:

    >>> matrix_divided([[1, 2], [3, 4, 5]], 2)
    Traceback (most recent call last):
    TypeError: Each row of the matrix must have the same size

A non-matrix raises a TypeError:

    >>> matrix_divided([[1, 2], "hello"], 2)
    Traceback (most recent call last):
    TypeError: matrix must be a matrix (list of lists) of integers/floats

A non-number divisor raises a TypeError:

    >>> matrix_divided([[1, 2], [3, 4]], "2")
