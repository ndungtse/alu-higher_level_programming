The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

A sorted print does not modify the underlying list:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

An empty list prints an empty sorted list:

    >>> empty = MyList()
    >>> empty.print_sorted()
    []

Negative numbers sort correctly:

    >>> neg = MyList()
    >>> neg.append(3)
    >>> neg.append(-2)
    >>> neg.append(0)
    >>> neg.print_sorted()
    [-2, 0, 3]
