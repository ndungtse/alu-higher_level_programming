# JavaScript - Warm up

First JavaScript scripts run with Node.js: constants and variables (`let` /
`const`, never `var`), reading command-line arguments with `process.argv`,
conditionals, loops, functions, recursion, objects, and exporting a function
from a module with `exports`.

## Requirements

- Interpreted on Ubuntu 20.04 LTS using `node` (version 14.x)
- First line of every file is `#!/usr/bin/node`
- `semistandard` (16.x.x) compliant; all files end with a new line
- All files are executable
- `var` is never used

## Tasks

| File | Description |
|------|-------------|
| `0-javascript_is_amazing.js` | Print the constant `myVar` ("JavaScript is amazing") |
| `1-multi_languages.js` | Print three lines about C, Python and JavaScript |
| `2-arguments.js` | Print a message depending on the number of arguments |
| `3-value_argument.js` | Print the first argument, or "No argument" (no `length`) |
| `4-concat.js` | Print `<arg1> is <arg2>` |
| `5-to_integer.js` | Print `My number: <n>` or "Not a number" |
| `6-multi_languages_loop.js` | Print the three lines from an array with one loop |
| `7-multi_c.js` | Print "C is fun" x times |
| `8-square.js` | Print a square of `X` of the given size |
| `9-add.js` | Print the sum of two integer arguments using `add(a, b)` |
| `10-factorial.js` | Print the factorial of the argument, computed recursively |
| `11-second_biggest.js` | Print the second biggest integer among the arguments |
| `12-object.js` | Change an object's `value` from 12 to 89 |
| `13-add.js` | Export an `add(a, b)` function (`13-main.js` uses it) |
